    How the radar works

    impliedValue scores every protocol from the snapshot's own figures only — never from a list of names:

    
    
    
    
    A protocol records no token when the snapshot carries no market cap,
    no CoinGecko id and no symbol for it. That is DefiLlama's record, not proof: a
    protocol on the board may still have a token its record does not carry. The
    implied value is this entry's own claim about what a launch would be worth if
    the protocol's record stayed as it is. It does not predict whether or when a
    token is issued.
    
    
    The board ranks every protocol that records no token and is not a wrapped,
    staked or bridged product of a token that already trades: the 40-protocol
    watchlist is the floor, and the early rows below it are the radar's own finds.
